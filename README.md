issues)

l (1 point) What are the lines of code (LoC) in the project?

example, for the repository https://github.com/jolav/betazone, the link
https://api.codetabs.com/v1/loc?github=jolav/betazone will lead to a JSON file with
the calculation. Another option is to use the Android Studio plugin:
https://stackoverflow.com/questions/25510185/count-lines-of-code-in-all-java-
